## What it is

KSP's ConfigNode on real files and edge cases: ConfigNode.Load(path) (File.ReadAllLines -> PreFormatConfig -> RecurseFormat), ConfigNode.Save(path) (StreamWriter, UTF-8 without BOM, Environment.NewLine = CRLF on Windows), ConfigNode.ToString() (\n line ends, includes node ids) and ConfigNode.Parse(string). Load returns a node named 'root'; Save writes root's values and child nodes without the root wrapper. Exact saved bytes are in confignode_roundtrip/saved/<id>.cfg and the parsed trees in confignode_roundtrip/trees/<id>.json.

## Conventions

- Numbers are exact: doubles are written as the shortest of G15/G16/G17 that round-trips, floats as the shortest of G6..G9; NaN and infinities are the strings "NaN", "Infinity", "-Infinity". Columns typed `f32` hold float32 values (compare in float32 ULPs).
- Rows are identified by the table's `key` columns; compare with `python -I harness/compare/compare.py`.
- Units: SI unless stated (m, s, kg, K); KSP pressure is kPa in CelestialBody and atm in engine curves; masses in engine tables are tonnes; forces from FlightIntegrator/ModuleEngines/ModuleLiftingSurface are kN.

## Files

- saved/<id>.cfg: exact bytes written by ConfigNode.Save (CRLF, UTF-8 without BOM). trees/<id>.json: parsed tree. synthetic_inputs/<id>.cfg: the exact synthetic input bytes.
- Notable behaviour: '//' starts a comment anywhere (so 'http://x' becomes 'http:'), comments are not preserved, node ids ('PART (id)') are kept by ToString but dropped by Save, a stray '}' at root level ends parsing (everything after it is lost), bare tokens not followed by '{' are dropped, '{'/'}' on the same line as text are split out.

## KSP methods used as oracles

- `ConfigNode.Load(string)`
- `ConfigNode.Save(string)`
- `ConfigNode.ToString()`
- `ConfigNode.Parse(string)`
