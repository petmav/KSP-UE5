## What it is

FloatCurve semantics. FloatCurve.Load/Add/Evaluate are KSP's own code (direct); the UnityEngine.AnimationCurve underneath is the harness's managed port of Unity 2019.4.18f1's native AnimationCurveTpl<float> (KspUnityShim), transcribed op-for-op from UnityPlayer.dll disassembly with Unity's public PDB symbols (re-hosted native; not executed natively). Values are float32. Sample times include every key time, the float32 neighbours of every key time, segment midpoints and a uniform grid extending 10% beyond the key range on both sides.

## Conventions

- Numbers are exact: doubles are written as the shortest of G15/G16/G17 that round-trips, floats as the shortest of G6..G9; NaN and infinities are the strings "NaN", "Infinity", "-Infinity". Columns typed `f32` hold float32 values (compare in float32 ULPs).
- Rows are identified by the table's `key` columns; compare with `python -I harness/compare/compare.py`.
- Units: SI unless stated (m, s, kg, K); KSP pressure is kPa in CelestialBody and atm in engine curves; masses in engine tables are tonnes; forces from FlightIntegrator/ModuleEngines/ModuleLiftingSurface are kN.

## Semantics a port must reproduce

- Evaluation (Unity AnimationCurveTpl<float>::Evaluate): outside [first,last] key time the value is clamped (t >= last returns last value exactly, t < first returns first value); inside, segment [L,R] with L.time <= t < R.time, dx = R.time-L.time, length = max(1e-4f, dx), d0 = length*L.outTangent, d1 = length*R.inTangent, dy = R.value-L.value, inv = 1/(length*length); a = (((d1+d0)-dy)-dy)*inv/length; b = (((dy+dy)+dy)-d0-d0-d1)*inv; c = L.outTangent; d = L.value; result = ((a*u+b)*u+c)*u+d with u = t-L.time. All float32, in this operation order. If L.outTangent or R.inTangent is +Infinity the segment is constant L.value (-Infinity is not special). One key: that value. No keys: 0.
- FloatCurve.Load: values split on ' ', ',', ';', tab; exactly 4 numbers -> Keyframe(t,v,in,out) via AddKey (no smoothing); any other count >= 2 -> AddKey(t,v), which inserts the key and recomputes the tangents of the key and both neighbours (first/last key: one-sided slope; middle: 0.5*m_right + 0.5*m_left with slopes zeroed when |dx| <= 1e-5). A later 2-value key therefore overwrites explicit tangents of its neighbours. A key whose time equals an existing key is dropped.
